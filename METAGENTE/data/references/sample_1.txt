OmniStream is a distributed, event-driven message broker built in Rust, designed for high-throughput streaming applications and microservices orchestration. It features an advanced pub/sub architecture based on Raft consensus, offering exactly-once delivery guarantees, tiered storage, and native Kubernetes support. The system handles millions of events per second with sub-millisecond latency and provides official client libraries for Python, Go, and Rust, alongside a RESTful management API.
