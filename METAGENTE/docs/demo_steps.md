# Live Demo Script

Use this step-by-step PowerShell script to demonstrate the prototype from a fresh terminal during a presentation.

### Step 1: Environment Setup
Explain that the prototype is lightweight and relies only on `rouge-score` for evaluation.
```powershell
# 1. Install dependencies
pip install -r requirements.txt
```

### Step 2: Show the Data Structure
Show the audience the file-based approach. Explain that instead of CSVs, we use distinct text files for easy inspection.
```powershell
# 2. View the mock README sample
Get-Content data/train/sample_1.txt

# 3. View the golden reference summary
Get-Content data/references/sample_1.txt
```

### Step 3: Run Standalone Evaluation (Optional)
Demonstrate that the evaluation metric script works independently.
```powershell
# 4. Test the ROUGE evaluator directly
python scripts/rouge_eval.py --reference "FastLogger is an ultra-fast logging library." --candidate "FastLogger is a fast logging tool."
```

### Step 4: Run the Metagente Optimization Cycle
Explain that the orchestrator will now run the sequential flow: Extractor -> Summarizer -> Eval -> Teacher -> Prompt Creator.
```powershell
# 5. Execute the main optimization loop
python scripts/consolidate_prompts.py
```

### Step 5: Inspect the Artifacts
Show the audience the deterministic outputs saved in the `runs/` folder.
```powershell
# 6. View the generated candidate summary
Get-Content runs/candidates/candidate_1.txt

# 7. View the ROUGE scores
Get-Content runs/metrics/metrics_1.json

# 8. View the Teacher's critique
Get-Content runs/logs/teacher_feedback.txt

# 9. View the final, optimized prompt generated by the loop
Get-Content runs/summaries/optimized_prompt_1.md
```

### Step 6: Explain Future Work
Open `scripts/consolidate_prompts.py` in your editor and show the four helper functions (`run_extractor`, `run_summarizer`, etc.). Point out the mocked returns and explain that integrating a live LLM requires changing exactly four lines of code inside these isolated functions.
