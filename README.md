# Artificial Intelligence & Data Science Portfolio

Welcome to my Artificial Intelligence and Data Science portfolio. This repository showcases a comprehensive collection of projects, demonstrating my expertise across various domains of AI, including Machine Learning (ML), Deep Learning (DL), Natural Language Processing (NLP), and AI Ethics. 

Each notebook in this repository is designed to solve specific challenges, employing state-of-the-art tools, algorithms, and best practices in the industry.

## 📂 Project Categories

### 🧠 1. Machine Learning & Data Science
Practical applications of predictive modeling, classification, and model explainability.

* **`ML_Predictive_Maintenance_LogisticRegression.ipynb`**
  A predictive maintenance project that anticipates industrial machine failures. It highlights the use of Logistic Regression, Scikit-Learn pipelines, and rigorous statistical evaluation metrics (e.g., Log-likelihood, Shannon Entropy, MCC) to minimize unplanned downtime.
* **`ML_XGBoost_SHAP_Explainability.ipynb`**
  Advanced predictive modeling leveraging the XGBoost algorithm. Focuses heavily on model interpretability and explainable AI (XAI) using SHAP (SHapley Additive exPlanations) values to understand feature importance and model decisions.
* **`ML_BreastCancer_Classification.ipynb`**
  A classification project focused on healthcare diagnostics, building models to accurately detect and classify breast cancer instances.
* **`DS_RandomForest_Transactions.ipynb`**
  Data Science project focusing on tabular transaction data (`train_transaction.csv`). It implements a Random Forest classifier to handle complex, high-dimensional datasets.

### 🕸️ 2. Deep Learning
Implementation of neural networks for computer vision and anomaly detection.

* **`DL_FashionMNIST_CNN.ipynb`**
  An image classification project using Convolutional Neural Networks (CNNs) to accurately classify clothing items from the FashionMNIST dataset.
* **`DL_Fraud_Detection_Autoencoders.ipynb`**
  An unsupervised Deep Learning approach to cybersecurity and finance. Implements Autoencoders to reconstruct data and detect anomalies, specifically targeting fraud detection.
* **`DL_Theoretical_Concepts_Report.ipynb`**
  A comprehensive theoretical report exploring the fundamental concepts, architectures, and mathematics behind Deep Learning models.

### 🗣️ 3. Natural Language Processing (NLP)
Text mining, conversational AI, and linguistic data processing.

* **`NLP_Text_Processing_Spacy.ipynb`**
  Advanced text processing pipeline using the `spaCy` library. It covers data cleaning (from `corpus_bruto.csv` to `corpus_limpio.csv`), tokenization, Entity Recognition (NER), and leverages custom tagging dictionaries (`diccionario_etiquetas.json`).
* **`NLP_Conversational_Agent_Design.ipynb`**
  The design and architectural planning of a conversational AI agent (chatbot), focusing on intent recognition and dialogue flow.
* **`NLP_Theoretical_Report.ipynb`**
  An in-depth theoretical report covering modern NLP paradigms, techniques, and evaluation metrics.

### ⚖️ 4. AI Ethics & Symbolic AI
Projects exploring the ethical implications of AI and classical symbolic reasoning.

* **`AI_Ethics_Algorithmic_Fairness_Audit.ipynb`**
  A critical ethical audit of automated, biometric-based recruitment systems (e.g., HireVue). The notebook analyzes algorithmic bias, privacy-by-design, the EU AI Act implications, and proposes a governance framework for fairness in High-Risk AI.
* **`AI_Symbolic_Planning_PDDL.ipynb`**
  Exploration of classical AI planning and symbolic reasoning using PDDL (Planning Domain Definition Language), featuring autonomous agent pathing and task solving (linked to the `pddl_urbanbot` environment).

## 🚀 How to Navigate
All projects are self-contained within Jupyter Notebooks (`.ipynb`). You can explore the code, visual outputs, and analytical markdown cells sequentially in each file. Dataset samples (such as `.csv` and `.json` files) are included to support the notebook pipelines.
